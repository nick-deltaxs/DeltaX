### 3. Accessibility Audit

**Tab order:**
- Verify that pressing Tab moves through interactive elements in a logical order on every page
- Order on home: Navbar links → Hero form → (scroll sections have no interactive elements until) Engine WaitlistForm → Footer links
- Order on contact: Navbar → form fields (Name → Email → Company → Challenge → Submit) → Footer

**Focus rings:**
- Every focusable element must have a visible focus indicator
- Buttons: `focus:ring-2 focus:ring-core-bright focus:ring-offset-2 focus:ring-offset-bg-primary`
- Links: `focus:outline-none focus-visible:ring-2 focus-visible:ring-core-bright`
- Inputs: `focus:ring-2 focus:ring-core-bright`
- If any element is missing a focus ring, add it

**Skip-to-content link:**
- Verify `layout.tsx` has a skip-to-content link as the first focusable element:
  ```tsx
  <a href="#main" className="sr-only focus:not-sr-only focus:absolute focus:top-4 focus:left-4 focus:z-[100] focus:bg-core-bright focus:text-bg-primary focus:px-4 focus:py-2 focus:rounded-lg font-body text-sm">
    Skip to content
  </a>
  ```
- Verify the `<main>` element has `id="main"` on every page
- If missing, add them

**ARIA attributes:**
- Navbar: `aria-label="Main navigation"` on the `<nav>` element
- Services dropdown: `aria-expanded`, `aria-haspopup="menu"`, `role="menu"` on dropdown, `role="menuitem"` on items
- WaitlistForm: `aria-label` on email input, `aria-live="polite"` on status message container
- ContactForm: `aria-label` on all inputs, `aria-live="polite"` on error/success messages
- Footer: `aria-label="Footer navigation"` on the footer `<nav>`
- Images/logos: `aria-hidden="true"` on decorative SVGs, `alt` text on meaningful images

**Semantic HTML:**
- Each page should have exactly one `<h1>`
- Heading hierarchy should not skip levels (h1 → h2 → h3, never h1 → h3)
- Sections should use `<section>` with `aria-labelledby` pointing to their heading, or `aria-label`
- Legal pages: proper `<h1>`, `<h2>`, `<p>`, `<ul>`, `<li>` hierarchy

**Fix any accessibility issues found.**
