### How to Contribute

1. **Clone the repository**
   ```bash
   git clone git@github.com:nick-deltaxs/DeltaX.git
   cd DeltaX
   ```

2. **Create your feature branch from Team-Deltax**
   ```bash
   git checkout Team-Deltax
   git pull origin Team-Deltax
   git checkout -b feature/your-feature-name
   ```

3. **Make your changes and commit**
   ```bash
   git add .
   git commit -m "feat: descriptive message about changes"
   ```

4. **Push to your branch**
   ```bash
   git push origin feature/your-feature-name
   ```

5. **Create a Pull Request to Team-Deltax branch**

### Commit Message Convention

- `feat:` - New feature
- `fix:` - Bug fix
- `docs:` - Documentation changes
- `style:` - Code style changes (formatting, etc)
- `refactor:` - Code refactoring
- `test:` - Adding or updating tests
- `chore:` - Maintenance tasks
